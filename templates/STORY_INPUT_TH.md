# แบบรับข้อมูลเรื่อง — ยังไม่ใช่ canon หรือ approval record

คัดลอกแบบฟอร์มนี้ไปยัง workspace ของเรื่อง กรอกเฉพาะข้อมูลที่เจ้าของเรื่องให้จริง ใช้ UNKNOWN เมื่อยังไม่รู้ และเก็บคำถามไว้ให้คนตัดสินใจ แบบฟอร์มนี้เป็นเอกสารรับข้อมูล ไม่ถูก import เข้า engine และไม่เปลี่ยน registry อัตโนมัติ ดู [คู่มือ E7](../ENGINE_E7.md) และ [schemas/v1](../schemas/v1/) ก่อนแปลงข้อมูลที่ผ่านการพิจารณาแล้ว

## แผนที่นำข้อมูลเข้าสู่ engine หลังการพิจารณา

| หมวดในแบบฟอร์ม | ไฟล์ที่เกี่ยวข้อง | วิธีรักษาขอบเขต |
| --- | --- | --- |
| ชื่อ/slug/ส่วนขยาย/กฎเฉพาะเรื่อง | `story.json` | ใช้ keys ตาม config schema version 1 เท่านั้น |
| ข้อเท็จจริงโลก | `data/canon.json` | `PROPOSED`/`UNKNOWN`/`DISPUTED` หรือ `LOCKED` ตามคำตัดสินจริง พร้อม origin/scope |
| ตัวละคร/knowledge | `data/characters.json` | IDs อ้างอิงได้; `after_scene` เป็นฉากที่มีอยู่และไม่ย้อน future knowledge |
| สถานที่/สิ่งของ/จำนวน | `data/locations.json`, `data/items.json`, `data/inventory_ledger.json` | ไม่เดาจำนวนหรือการโอน; ตรวจ chronology |
| ตอน/ฉาก/เหตุการณ์ | `data/episodes.json`, `data/scenes.json`, `data/events.json`, `scenes/` | ใช้สถานะงานจริง เช่น OUTLINE/PLANNED ไม่เลื่อนเอง |
| state/history | `data/story_state.json`, optional `data/state_history.json` | ต้องมีหลักฐานอิสระและ deltas ที่เข้าเกณฑ์; ช่องว่างยัง UNKNOWN |
| style | `bible/STYLE_GUIDE.md` | กฎของเรื่องที่เลือกเท่านั้น |
| recap/provenance | `ledger/index.json`, `ledger/episodes/` | เพิ่มหลังมี source และการตัดสินใจจริง; template ไม่สร้าง approval |

| ช่อง | ค่า |

| คำตัดสิน/รายการที่ยอมรับ | PENDING |
| รายการที่ยังเป็น proposal/คำถาม | UNKNOWN |
| ผู้ตัดสินใจและหลักฐานอ้างอิงจริง | UNKNOWN |
| เวลาที่เกิดการตัดสินใจจริง | UNKNOWN |
| ขอบเขตที่อนุญาตให้ updater ทำต่อ | UNKNOWN |

ไม่กรอก PR/SHA/ชื่อคน/เวลาอนุมัติที่แต่งขึ้น การผ่าน tests, local commit, local APPROVED label หรือ observed software merge ไม่ยืนยัน human editorial approval เครื่องมือเตรียมหลักฐานและข้อเสนอให้คนตัดสินใจเท่านั้น
