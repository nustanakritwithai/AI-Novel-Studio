# Character Bible — memory beyond character bios

`data/characters.json` คือ index ของตัวละคร ทุกตัวละครเมื่อเขียนจริงควรมีรายละเอียด:

1. **Identity:** ID, ชื่อ/ชื่อชั่วคราว/ชื่อในเกม, บัญชี VR, สิ่งที่ล็อก, สิ่งที่ยังไม่รู้
2. **External:** บุคลิก น้ำเสียง วิธีพูด ภาษา การเคลื่อนไหว ข้อจำกัด
3. **Internal:** ความต้องการ ความกลัว ปม ความเชื่อ จุดบอด แรงจูงใจที่เปลี่ยนไป
4. **Capabilities:** ทักษะจริง ทักษะเกม อาวุธ และสิ่งที่ยังทำไม่ได้
5. **Resources:** ไอเทม อาวุธ HP/บาดเจ็บ ฐาน จุดเกิด (รู้จริงเท่านั้น)
6. **Relations:** รู้จักใคร มองใครเป็นมิตร/ศัตรู หลักฐานต่อฉาก
7. **POV Knowledge:** รู้เหตุการณ์ไหนเมื่อใด; อย่าสวมความรู้ผู้ชมให้ตัวละคร
8. **Arc:** จุดเริ่ม เปลี่ยนใจ ความผิดพลาด ผลที่ต้องจ่าย และสถานะล่าสุด
