# Voice, scene craft and story quality

## Style

- นิยายภาษาไทย อ่านคล่อง ภาพชัด เหมือนดูภาพยนตร์ แต่ยังเป็น prose ไม่ใช่บทสรุปเกม
- ทุกฉากต้องมี **Goal → Resistance → Choice → Consequence**
- ให้ระบบเกมเป็นแรงกดดันเชิงเหตุและผล ไม่ใช่อธิบาย UI ต่อเนื่องหลายหน้า
- ฉากแรกเป็นประสบการณ์ส่วนตัวและความตื่นเต้นการสำรวจ ไม่ต้องรีบเล่า lore ของการแข่งขันใหญ่
- บทพูดสะท้อนสถานการณ์และนิสัย เงียบ/ลังเล/การตัดสินใจก็เล่าเรื่องได้
- แอ็กชันระยะประชิดมีจังหวะและต้นทุน ไม่ให้พระเอกชนะง่าย

## Scene acceptance questions

- ถ้าตัดฉากนี้ออก เรื่องเปลี่ยนไหม? ถ้าไม่ เปลี่ยนหรือรวมฉาก
- ตัวละครต้องเลือกอะไรและเสียอะไร?
- การเคลื่อนที่ ทรัพยากร ความรู้ สัมพันธ์ ถูกบันทึกแล้วหรือยัง?
- มีประโยคไหนหลุดจาก POV ไปเป็นผู้บรรยายรอบรู้โดยไม่ตั้งใจ?
- มีคำอธิบายกลไกเกมที่ไม่ได้ยืนยันจากแหล่งหรือไม่?

## Pacing EP-001

1. หยั่งรู้โลกใหม่ → ระบบช่วยเหลือ
2. ลงแรงเก็บไม้ → เจอผู้เล่นอื่นอย่างอ้อม ๆ จากบ้านที่ปรากฏ
3. เลือกทำเลใหม่ → เตรียมอาวุธ
4. กล่องเศษวัสดุบนถนน → โดนซุ่ม → ไฟต์เฉียดฉิว
5. เก็บของ → ตัดสินใจกลับสร้างบ้าน เพื่อปิด loop 'ตั้งหลักให้ได้'
