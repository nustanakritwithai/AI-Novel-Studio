# บันทึกตรวจสอบแหล่งอ้างอิงบ้าน

ตรวจเมื่อ 2026-10-23 สำหรับข้อเสนอการออกแบบบ้านของ Last Island เท่านั้น แหล่งข้อมูล RustBases ทั้ง 10 รายการด้านล่างเปิดจากหน้ารายการโดยตรง หน้าเหล่านี้ส่วนใหญ่แสดงชื่อ ผู้สร้าง แท็ก และข้อความสรุปที่เว็บไซต์จัดทำ แต่ไม่มี transcript และไม่ได้แสดงผังให้ตรวจ จึงแยกข้อมูลชื่อ/แท็กที่อ่านได้ออกจากคำอธิบายของเว็บไซต์ใน [sources.json](./sources.json) อย่างชัดเจน ไม่อ้างว่าตรวจแผนก่อสร้างหรือกลไกในวิดีโอแล้ว

นี่คือการคัดตัวอย่างเพื่อครอบคลุมแกนขนาดเล็ก การขยาย กลุ่มผู้ใช้ ความสบาย รูปทรงที่มีศูนย์กลาง พื้นที่เกษตร และมิติแนวตั้ง ไม่ใช่การสำรวจ RustBases ทั้งเว็บไซต์ สรุปที่เว็บไซต์สร้างอาจช่วยชี้หัวข้อให้ติดตาม แต่ไม่ได้ใช้แทนคำให้การของผู้สร้างหรือหลักฐานจากวิดีโอ เมื่อหน้าไม่มี transcript จะไม่อนุมานตำแหน่งห้อง บันได จำนวนชั้น หรือรูปทรงจากชื่ออย่างเดียว

## แหล่งรูปผังและตัวอย่างแนวตั้ง

- [GUIDE-001 — The Best Rust Starter Base 2021](https://guided.news/en/guides/rust-best-starter-base-2021-tips-tricks/) โดย Kevin Willing อธิบายแบบเริ่มต้น 2x2 และเชื่อมไปยัง [ภาพผัง](https://guided.news/wp-content/uploads/2021/01/rust-starter-base-2021-2x2-grundriss-bauplan.jpg) ข้อสังเกตจากการตรวจภาพในโครงการคือแกนสี่เหลี่ยมร่วมกับส่วนต่อสามเหลี่ยมและด้านหน้าที่เป็นปลายแหลม แต่ภาพมุมมองนี้ไม่พอให้นับขอบหรือ tile ทั้งหมด จึงใช้เป็นเพียงแรงบันดาลใจระดับรูปแบบ ไม่ทำสำเนาผัง
- [CH-001 — Easiest Bunker Base in RUST](https://www.corrosionhour.com/easiest-bunker-base/) โดย Digital Ghost ถอดความวิดีโอ Vice และบรรยายบันไดรูปตัว L ที่ขึ้นไปยังชั้นเก็บของรอง ใช้เพียงคำศัพท์เรื่องทางสัญจรแนวตั้งและพื้นที่ใต้บันได
- [CH-002 — Aggravator RUST Base Design](https://www.corrosionhour.com/aggravator-rust-base-design-2019/) โดย Digital Ghost ว่าด้วยแบบของ Evil Wurst; transcript ระบุพื้นที่ใช้ชีวิตและทำงานช่างบนชั้นสอง ห้องเสริม และทางขึ้นหลังคา ภาพเก่าประกอบที่ผู้ดูแลโครงการตรวจเห็นมวลส่วนบนสูงกว่าส่วนหลังคาด้านล่าง แต่ภาพไม่ได้ยืนยันเส้นทางขึ้นหรือการใช้งานระเบียง
- [CH-003 — Trio Stability Bunker Base Design](https://www.corrosionhour.com/trio-stability-bunker-base-design-2019/) โดย Squishface อ้างแบบของ Everherd; บทความและ transcript แบ่งพื้นที่เป็นชั้นล่าง ชั้นอยู่อาศัยตรงกลาง และชั้นบนสำหรับการต่อสู้ทางไกล หน้าแจ้งว่าวิดีโอต้นฉบับถูกนำออกแล้ว จำนวนชั้นจึงอ้างจากข้อความในบทความ ไม่ได้อ่านจากภาพ ภาพเก่าประกอบที่ผู้ดูแลโครงการตรวจเห็นมวลกลางสูงกว่าปีกด้านข้าง

Corrosion Hour เป็นคู่มือ Rust ปี 2018–2019 และ Guided เป็นคู่มือ Rust ปี 2021 แหล่งเหล่านี้ช่วยเสนอคำถามเรื่องการจัดหน้าที่ตามระดับ ความสัมพันธ์ระหว่างพื้นที่เดินกับพื้นที่ใช้งาน และการอ่านรูปทรงภายนอกเท่านั้น ไม่ได้ยืนยันกฎความสูง การสร้างบันได การเปิดช่องพื้น การรับน้ำหนัก หรือฟิสิกส์ของ Last Island

## ขอบเขตและการให้เครดิต

ข้อเสนอที่อาศัยงานเหล่านี้ต้องออกแบบรูปทรง ผัง และรายละเอียดใหม่ทั้งหมด ไม่คัดลอกภาพหรือแผนบ้าน และไม่ย้ายระบบป้องกัน การบุกฐาน การผลิตทรัพยากร ต้นทุน หรือค่าประสิทธิภาพจาก Rust เข้ามาใน Last Island คำกล่าวเหล่านี้ไม่ใช่ข้อมูลจากบทหรือ canon ของเรื่อง; กลไกของเกมในฉากยังคงเป็น UNKNOWN จนกว่าจะมีหลักฐานแยกจากโหมดเกมที่เลือกไว้ ไม่มีการกำหนดเจ้าของบ้าน บุคคล กลุ่ม หรือเหตุการณ์ในเรื่องจากแหล่งภายนอก

ชื่อรายการและชื่อผู้สร้างที่ปรากฏในตารางใช้เพื่อระบุแหล่งที่มา ส่วนบทสรุปภาษาไทยใน [sources.json](./sources.json) เป็นการถอดความสั้น ๆ พร้อมระดับหลักฐานและข้อจำกัด ไม่คัดลอกข้อความบรรยายหรือไฟล์ภาพจากแหล่งใด
