# บัตรอ้างอิงชั้นป้องกันสำหรับงานเขียน — PROPOSED

ใช้เป็น **เครื่องช่วยจำสำหรับนิยาย** เท่านั้น ไม่ใช่แบบก่อสร้าง คู่มือเล่นเกม การคำนวณความแข็งแรง หรือกฎ runtime ตัวอย่าง `SYN-ENV-*` ด้านล่างเป็นฉากสังเคราะห์ที่ไม่ผูกกับเนื้อเรื่องและไม่ใช่บ้านที่รับรองแล้ว

## รูปแบบบัตรที่ต้องบันทึก

ต่อหนึ่งบ้านและหนึ่งฉาก ให้เก็บ `house_ref`, `target_blueprint_ref`, `snapshot_id`, ขอบเขตเวลาโลก, ขอบเขตการเปิดเผยในเรื่อง, POV/ผู้รู้, `parts[]`, `links[]`, แหล่งที่มา และข้อไม่ทราบ แยก **แบบเป้าหมาย** ออกจาก **สภาพที่สร้างแล้ว ณ ฉากนั้น** และแยกทั้งสองอย่างจากสิ่งที่ POV รู้

แต่ละ `part` ต้องมี stable ID, ชนิดชิ้นส่วน, ด้าน (`N/S/E/W/TOP`), ชั้น, สถานะก่อสร้าง, usability, damage/repair, material tier, ค่าความหนาเชิงกายภาพ และ symbolic strength tier แยกช่องกัน ค่า/สถานะที่ไม่มีหลักฐานเป็น `UNKNOWN` หรือ `null`; ห้ามอนุมานจากแปลน

## ทิศทางที่ผู้ใช้ให้ไว้และขอบเขต

- บ้านที่อยู่อาศัยอยู่ด้านใน แยกจากชั้นป้องกันภายนอกทาง N/S/E/W และด้านบน (`TOP`); บัตรนี้ยังไม่กำหนดพื้น/ชั้นล่าง
- จำนวนชั้นอาจเพิ่มเป็นชั้น 1, 2 หรือ 3 แต่ไม่มีตารางเวลา กฎเลื่อนระดับ หรือการสร้างอัตโนมัติ
- ระบุแต่ละชั้นและประตูด้วย ID ของตนเอง; ประตูเรียงชั้นเป็นสัญลักษณ์การเชื่อมต่อ ไม่ยืนยันว่ามีช่องเปิดจริง เปิดได้ หรือใช้ได้
- เวลาโลกที่ก่อสร้าง, เวลาเปิดเผยข้อมูลแก่ผู้อ่าน, และความรู้ของ POV เป็นคนละช่อง; หากไม่ทราบให้คง `UNKNOWN`
- สถานะ `COMPLETED` ไม่ได้แปลว่าใช้ได้; ความเสียหาย/ซ่อมแซมเปลี่ยนเฉพาะชิ้นส่วนที่มีหลักฐานระบุ ไม่มีการเอาชั้นอื่นหรือประตูออกโดยอัตโนมัติ
- เก็บ snapshot เดิมไว้ ไม่เขียนทับสภาพบ้านในฉากก่อนหน้า การแก้ข้อมูลให้เพิ่ม revision/record ที่ supersede พร้อมเหตุผลและหลักฐานโดยยังย้อนดูของเดิมได้
- ห้ามคำนวณเส้นทางที่ดีที่สุด อัตราส่วน ค่าความทนทาน HP วัสดุ/ทรัพยากร ปริมาณจู่โจม หรือค่าใช้จ่าย

## ตัวอย่างสังเคราะห์ที่ไม่ใช่เรื่องจริง

`SYN-ENV-A` (world tick 10): ชั้นภายนอกชั้น 1 ครบ N/S/E/W/TOP มีสถานะก่อสร้าง `COMPLETED`; usability และประตูยัง `UNKNOWN` เพราะเหตุการณ์นี้ไม่ได้ระบุไว้

`SYN-ENV-B` (world tick 20): ชั้นภายนอกชั้น 2 ครบ N/S/E/W/TOP เป็น `COMPLETED`; ชั้น 3 ไม่มีวันกำหนดและคง `UNKNOWN`; การสร้าง/ใช้ประตูยังไม่ยืนยัน

`SYN-ENV-C` (world tick 30): ระบุความเสียหาย/ทะลุเฉพาะ `SYN-ENV-L1-N`; ชั้นอื่นและประตูคงสถานะจาก B ตามที่ระบุว่าไม่เปลี่ยน ไม่มีการอนุมานว่าชั้นป้องกันทั้งหมดหายไปหรือว่าเส้นทางใดใช้งานได้

ทางเชื่อม N ต่อไปนี้เป็น **สัญลักษณ์ของแปลน**: `EXTERIOR → SYN-ENV-DOOR-OUTER-N → SYN-ENV-L1-N → SYN-ENV-DOOR-L1-L2-N → SYN-ENV-L2-N → SYN-ENV-DOOR-INNER-N → SYN-ENV-INNER-001`. ไม่ใช่ topology ที่ยืนยันแล้ว; ชั้น 3/ประตูชั้น 3 ไม่ได้อยู่ในเส้นทางนี้ และไม่มีประตูบน TOP ที่อนุมานไว้

## ข้อความวัสดุที่ต้องคงที่

- ข้อความผู้ใช้ตามต้นฉบับ: `ประตูหินมีความหนาเท่ากับกำแพงไม้` — ผู้ใช้ชี้แจงว่า “เท่ากัน” หมายถึง **ระดับความแข็งแกร่งในเกม**; เป็นรายงานจากผู้ใช้ที่ยังไม่ยืนยัน เก็บใน `symbolic_strength_tier` โดยไม่ใส่ค่าตัวเลข
- ข้อความผู้ใช้ตามต้นฉบับ: `ประตูเหล็กมีความหนาเท่ากับประตูหิน` — ความหมายที่รายงานเป็นระดับความแข็งแกร่งในเกม แต่การเทียบกับประตูหินยังเป็นข้อความตามต้นฉบับที่ไม่ยืนยัน และรอคำชี้แจงว่าตั้งใจหมายถึงกำแพงหินหรือไม่
- ทั้งสองข้อความไม่ให้ค่าความหนาเชิงกายภาพ, จำนวนชั้น, HP, ค่าป้องกัน หรือลำดับ/สูตรเพิ่มระดับ ให้ช่องเหล่านี้เป็น `null`/`UNKNOWN`; อย่าแก้คำหรือสร้างอัตราส่วนแทนผู้ใช้

## ก่อนนำไปใช้ในการเขียน

ตรวจว่า ID/ฉากอยู่ใน namespace สังเคราะห์หรือมีหลักฐานผูกกับเรื่องจริงอย่างชัดเจน หากไม่มีหลักฐาน ให้บ้าน เจ้าของ/กลุ่ม ฉากจริง สถานะรับรอง วันเวลา ระยะก่อสร้าง usability และ POV เป็น `UNKNOWN`; อย่าติดป้าย `ADOPTED` จากตัวอย่างหรือไฟล์ร่างนี้ การยืนยันข้อมูลไม่ใช่การอนุมัติ canon และบัตรนี้ไม่แก้เรื่องเล่า canon หรือ runtime
