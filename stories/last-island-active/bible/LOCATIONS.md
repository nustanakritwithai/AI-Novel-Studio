# Location Bible — spatial continuity

สถานที่มี `LOC-ID` ใน `data/locations.json`; สำหรับแต่ละฉากบันทึก:

- อยู่โลกจริง (REAL) หรือเกม (VR)
- จุดเริ่ม/ปลายการเคลื่อนที่, ระยะเวลาโดยประมาณ (UNKNOWN หากไม่มีหลักฐาน)
- ลักษณะภูมิประเทศและทางเข้าที่รู้จากเกม
- มีทรัพยากร/ผู้เล่น/ภัยคุกคามใดที่พิสูจน์หรือกำหนดแล้ว
- แผนที่ผู้เล่นเห็น แตกต่างจากแผนที่ omniscient ของคนดูหรือไม่
- การเดินทางระหว่างจุดต้องมีเหตุการณ์และเวลา

EP-001: LOC-001 ห้องจริง → LOC-002 จุดเกิด → LOC-003 ย่านบ้านมือใหม่ → LOC-004 ถนน (พบกล่อง/ปะทะ) → LOC-005 ทำเลสร้างบ้านใหม่
