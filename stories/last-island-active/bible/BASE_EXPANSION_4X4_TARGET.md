## 1. ผัง 4×4 หน่วยพื้น ชั้นล่าง (เป้าหมาย)

```text
                         ด้านนอก
          กำแพงขอบนอกของฐาน 4×4
            ┌────┬────┬────┬────┐
            │ P  │ P  │ P  │ P  │
            ├────┼────┼────┼────┤
            │ P  │ C  │ C  │ P  │
            ├────┼────┼────┼────┤
            │ P  │ C  │ C  │ P  │
            ├────┼────┼────┼────┤
            │ P  │ P  │ P  │ P  │
            └────┴────┴────┴────┘

          P = ชั้น 1 ทางเดินโล่งภายในวงแหวน
          C = แกนบ้านเดิม 2×2 ซึ่งมีกำแพงเดิมคั่น
```

- ขนาด **4×4 หน่วยพื้น** = 16 ช่อง: `C` = 4 ช่องแกนกลาง, `P` = 12 ช่องรอบนอก
- `P` ทั้ง **12 ช่อง** เป็น **ทางเดินชั้นล่างชุดเดียวกันที่ต่อถึงกัน** เดินวนตามขอบแกนกลางได้ครบทุกด้านและทุกมุมโดยไม่ถูกผนังแบ่งตัดกลางทาง
- **ความกว้างทางเดินตามผัง = 1 หน่วยพื้น** รอบแกนกลาง 2×2
- คำว่า **ทางเดินโล่ง** หมายถึง *ไม่กั้นห้องหรือผนังที่ขวางวงทางเดิน*: ยัง **ไม่ยืนยันว่าไม่มีหลังคาคลุม** หรือว่าพื้นที่ทั้งหมดเป็นที่โล่งกลางแจ้ง
- อย่าถือว่าทางเดินทั้ง 12 ช่องเป็นห้องใหม่ และอย่าย้ายกล่อง โต๊ะคราฟต์ ที่นอน หรือเตาเผาจากบ้านเดิมเข้าแนว `P` เอง
- ทางเข้าจากภายนอกเข้าวงแหวน / จากวงแหวนเข้าสู่ห้อง 2×2 **ยังไม่กำหนดตำแหน่งและรูปแบบประตู** แต่เมื่อสร้างเสร็จต้องไม่ทำให้เส้นทางภายในวงแหวนขาดตอน

## 2. กำแพงป้องกันสองแนว (แนวด้านข้าง)

จากด้านนอกมาถึงห้องชั้นในต้องผ่านลำดับ:

**กำแพงรอบฐาน 4×4 → วงทางเดินโล่งชั้น 1 → กำแพงบ้านเดิม 2×2 → ห้องภายใน**

- มี **กำแพงสองแนว** เท่านั้น: กรอบนอก 4×4 และกรอบบ้านเดิม 2×2 ไม่ใช่กำแพงเดิมแล้วบวกอีก 2 แนว
- การมีกำแพงสองแนวไม่ใช่การกำหนดจำนวนระเบิดหรือจำนวนการโจมตีเพื่อเจาะสำเร็จ กฎความเสียหายเกมยัง UNVERIFIED
- รูปทรงผนัง/วัสดุส่วนต่อเติม/ประตู/ความทนทาน **ยังไม่ได้กำหนด**

## 3. ชั้นสองและชั้นยิง (เป้าหมาย ยังไม่สร้างเพิ่ม)

- ขอบรอบนอกของชั้นสองเป็น **พื้นที่ชั้นยิงรอบนอก** พร้อม **กำแพงเตี้ย** ริมขอบเพื่อกำบัง ไม่ใช่ผนังสูงปิดเป็นห้องรอบวง
- กำแพงเตี้ยบริเวณชั้นยิง **ไม่นับเป็นกำแพงป้องกันแนวที่สาม**
- กลางชั้นสองยังต้องกำหนดพื้นที่ยืน ตำแหน่งช่องเชื่อม ตำแหน่งบันไดและการขึ้นลงที่ใช้ได้จริง **ก่อนเขียนเป็นฉากใช้งาน**
- เหนือแกน 2×2 มีหลักซ้อนชั้นป้องกันด้านบนตามแบบที่ผู้เขียนกำหนด แต่ **ระยะ/แผ่นเพดาน/หลังคา/รูปตัดแนวดิ่งยังไม่กำหนด** ไม่ถือเป็นชั้นอยู่อาศัยที่สาม

## 4. เสาหลักและสิ่งที่ห้ามเติมเอง

- **มีเสาหลักเพียง 1 ต้น** ตรงกลางบ้านตามแบบของผู้เขียน
- ไม่เพิ่มเสาตามจำนวนช่องพื้น จำนวนชั้น หรือแนวผนัง
- ไม่เพิ่มฐานสามเหลี่ยมหรือส่วนยื่นนอก 4×4 เอง
- วัสดุผนังส่วนใหม่ จำนวน/ตำแหน่งประตู ทางเข้าวงแหวน ตำแหน่งบันได การเข้าถึงชั้นยิง และรายละเอียดหลังคาเป็น `TBD`
