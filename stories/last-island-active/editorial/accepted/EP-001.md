# EP-001 — บ้านหลังแรก
**Memory status:** AUTHOR ACCEPTED IN CHAT (DEC-004); GitHub reviewer approval NOT OBSERVED. **Source:** `drafts/EP-001/CH-01-FULL-DRAFT.md`, merged PR #13.

ชายหนุ่ม **ชาวไทย** เริ่มเล่น Last Island ผ่าน Full-Dive VR เป็นการส่วนตัวในห้องของตน ไม่ได้เปิดสตรีมหรือเข้าการแข่งขันโลก ระบบแนะนำให้หาไม้ สร้างที่พัก และทำเตียง เขาวางแผนสร้างบ้าน **2×2 ชั้นเดียว** แต่พบว่าบ้านผู้เล่นเริ่มใหม่อยู่รวมกันหนาแน่น จึงเปิดแผนที่และเลือกย้ายทำเล ก่อนเดินทางเขาคราฟต์ **ไม้เบสบอล** เป็นอาวุธชิ้นแรก ระหว่างเดินบนถนนเก็บวัสดุจากกล่องเศษวัสดุ **หนึ่งกล่อง** และถูกผู้เล่นอีกคนถือไม้เบสบอลซุ่มโจมตี เขาชนะอย่างหวุดหวิด เก็บ **หินและเศษวัสดุ** ที่คู่ต่อสู้ทำตก แล้วไปยังพื้นที่เลือกสร้างบ้าน

**สถานะสิ้นตอนจากต้นฉบับที่ผู้เขียนรับรอง:** บ้านไม้ขนาด 2×2 มีพื้น ผนัง ประตู และหลังคาพื้นฐาน เข้าไปอยู่ด้านในได้ แต่ **ยังไม่มี** โต๊ะคราฟต์ กล่องเก็บของ หรือเตียง จึงเริ่มบทที่ 2 จากการจัดอุปกรณ์เหล่านั้น

**Continuity:** ตัวละครหลักคือ `CHAR-001`, เป็นคนไทย ชื่อจริงและอายุยัง UNKNOWN; คู่ต่อสู้ไม้เบสบอลคนแรกคือ `CHAR-002` ไม่ใช่ตัวละครจากบทที่ 2 โดยอัตโนมัติ. จำนวนไม้ หิน เศษวัสดุและพลังชีวิตที่เหลือ **UNKNOWN**. ภารกิจแข่งขันโลก 100 คนเป็นเหตุการณ์ในอนาคต.
