# EP-002 — ธนูแรกและกำแพงหิน
**Memory status:** AUTHOR ACCEPTED IN CHAT (DEC-004); GitHub reviewer approval NOT OBSERVED. **Source:** `drafts/EP-002/CH-02-FULL-DRAFT.md`, merged PR #13.

พระเอกเริ่มจากภายในบ้านไม้ **2×2** ใช้วัสดุที่เก็บมาสร้าง **โต๊ะคราฟต์** พบสูตรที่นอน กล่องเก็บของขนาดเล็ก ยา โต๊ะเรียนรู้และสูตรอีกมากที่ยังไม่เรียนรู้ เขาสร้างกล่อง ที่นอน และเครื่องมือขุดหิน เพราะต้องการอัปเกรดบ้านทั้งหลังให้แข็งแรงกว่าบ้านไม้ก่อนออฟไลน์ ระหว่างเก็บหินถูกผู้เล่นถือ **ธนู** ซุ่มยิง เขาหลบหลังโขดหิน แต่ฝ่ายตรงข้ามเดินอ้อมจนได้มุมยิงและทำให้เขาตาย ของที่พกไปตก เขาจึงเกิดใหม่ที่ **เตียงในบ้าน** แล้วตัดไม้คราฟต์ธนูและลูกธนูเพื่อกลับไปชิงของคืน

เมื่อกลับไปจุดตายเขาไม่พบมือธนู แต่พบฐานผู้เล่นขนาดประมาณ **4×4** และเห็นผู้เล่นสองคน (ถือธนู/ไม้เบสบอล) เขาซุ่มยิงผู้เล่นถือธนูก่อนจนล้ม แล้วยิงคนถือไม้เบสบอลที่พยายามหนี จากนั้นเก็บทรัพยากรกลับบ้านอย่างปลอดภัย อัปเกรดโครงสร้างหลักบ้าน 2×2 เป็น **หิน** ต่อบันได ชั้นยิง และกำแพงเตี้ยไว้ใช้บัง ก่อน **ออกจากเกมไปพักผ่อน** ในห้องโลกจริง

**สถานะสิ้นบท:** ตัวละครอยู่ในโลกจริงหลังออฟไลน์ บ้านในโลก VR ยังอยู่ที่เดิมแบบหินพร้อมชั้นยิง; โต๊ะคราฟต์ กล่องเก็บของและที่นอนติดตั้งไว้; สร้างและใช้ธนูแล้วแต่จำนวนลูกธนูที่เหลือไม่ทราบ. ตายหนึ่งครั้งในบทนี้และเอาชนะผู้เล่นสองคน. จำนวนทรัพยากรทุกชนิด/HP **UNKNOWN**. คนถือธนูที่ฐาน 4×4 เป็นคนเดียวกับคนยิงครั้งแรก **ยังเป็นข้อสันนิษฐานจาก POV ไม่ยืนยันตัวตน**. ระบบคราฟต์/เกิดใหม่/ดรอปไอเทมเป็นกฎในนิยายฉบับนี้ ยังไม่ยืนยันว่าใช้ได้จริงทุกโหมดของเกมต้นแบบ.
