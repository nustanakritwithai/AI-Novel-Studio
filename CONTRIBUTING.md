# Contributing to the engine

Read `AGENTS.md` and `ENGINE_E1.md`. Keep engine changes on a feature branch and verify all existing regressions plus story-isolation and example-integrity tests. Report actual results in a draft PR and leave approval/merge decisions to the user.

For changes inside a story, read that story's `AGENTS.md`, `story.json`, canon, and approved state first. Story files and relative evidence paths belong to that root. Changing engine layout does not approve prose or promote canon.

The original Last Island contribution guide is preserved at `stories/last-island/CONTRIBUTING.md`. No external integrations or paid API calls are needed for local testing.
